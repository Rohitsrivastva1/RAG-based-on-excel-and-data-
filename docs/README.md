### 📋 System Features

- **Data Ingestion**: Excel/CSV upload, SQL database connections
- **AI Processing**: LangChain agents with LlamaIndex RAG
- **Natural Language Queries**: Ask questions in plain English
- **Dynamic Visualizations**: Auto-generated charts and graphs
- **Modern UI**: Dark theme with ChatGPT-like interactions
- **Export Options**: CSV, PNG, PDF export capabilities

### 🔧 Technology Stack

- **Frontend**: React, Ant Design, Plotly.js
- **Backend**: FastAPI, Python
- **AI/ML**: LangChain, LlamaIndex, Google Gemini
- **Database**: PostgreSQL, MySQL, SQLite
- **Vector Store**: FAISS
- **Visualization**: Plotly.js
